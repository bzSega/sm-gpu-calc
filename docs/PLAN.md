# SM GPU Calc — план развития

Актуализирован 2026-09-29. Продуктовые цели: [PRD.md](PRD.md).
Реализованные формулы, форматы и ограничения: [UNIFIED-SCENARIO.md](UNIFIED-SCENARIO.md).
Учебные допущения и измеренные характеристики всегда различаем.

## Реализовано

- [x] Единый интерфейс: пример / ручная нагрузка / CSV → модель и GPU → результат.
- [x] Дискретно-событийная FIFO-очередь на 1–8 репликах.
- [x] Параллельные запросы с явной учебной кривой прироста скорости.
- [x] Допуск по KV-памяти и свободным слотам; освобождение KV при завершении.
- [x] Реальный момент первого токена в расписании, очередь и стоимость прогона.
- [x] Общий каталог сценарных профилей в scenario-core.js.
- [x] Timeline, воспроизведение, inline-стойка, активный и свободный KV.
- [x] Сравнение с вариантом A на одной нагрузке.
- [x] CSV результатов, JSON /2, миграция сценариев /1 в последовательный режим.
- [x] 25 семантических тестов и проверки рендера поставки.
- [x] ZIP по явному списку файлов, версии JS против устаревшего кэша.
- [x] Один актуальный калькулятор; отдельные README RU/EN и английские скриншоты.

- [x] Демо OpenClaw на живых итогах токенов: 3 пользователя × 6 вызовов; разбивка по вызовам реконструирована.
